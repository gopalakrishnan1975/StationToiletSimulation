# AI Policy Laboratory: Railway Station Sanitation (v4)

A lecture-friendly **interactive policy simulator**, evolving from queue management through engineering, water and wastewater utilities, cleaning workforce, coach cleanliness, social welfare, and the concept of **clean basic station toilets funded as a railway service entitlement**.

## Run locally

```bash
pip install -r requirements.txt
streamlit run dashboard.py
```

For modular HTTP endpoints: `uvicorn api:app --reload`, then `/docs`. Docker Compose is provided as an architectural example. Services are Python modules behind one API process, **not independently deployed microservices**.

## Narrative
10 short story steps; each connects directly to a working UI tab. Recommended lecture 35–45 min, with at least 10 min of audience scenario testing.

## Basic policy financing
Budget allocation from existing fare receipts is **not** an automatic fare increase. An alternative incremental fare or passenger-km surcharge is a sensitivity scenario. Tariffs are transfers, not gross welfare benefits. Price response, health impacts and equity weights require pilot calibration.

## Cost reference
36 fixtures; three 600m-platform clusters; GLR, OHT, pumps, STP, equalization, electrical supply; ~₹2.8 crore initial CAPEX and ~₹1.27 crore annual OPEX as provisional order-of-magnitude estimates. Actual calculations are generated by the model and may differ from those rounded anchors. Reconcile tariffs with current Indian Railways policy and verify labor/engineering rates before approval.

## Pilot evaluation
Report station WC utilization, female queue percentiles, hours out of service, hourly cleanliness audits, water kL/day, STP outlet quality, costs per usable clean visit, onboard WC cleanliness and sanitation complaints. Use matched-control / stepped-wedge implementation with clear ethics and access protection.

## Caveat
Research / teaching prototype only. The welfare model is partial equilibrium. Do not use for tender BOQs, legal tariff authority or investment approval without detailed calibration and engineering review.
